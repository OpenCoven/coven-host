First sync

Send a field note.

  1. Open Coven Host. Setup starts the peer and opens your Coven folder.
  2. Open Castles/demo/files/. In any text editor, write a line and save it there as field-note.md. Host picks up the edit automatically.
  3. Reopen Coven Host to check the setup. If you use the Host CLI with this folder’s profile, run coven host sync, then coven host status. When sync finishes successfully, the phase reads synced.

FAQ

Using Host.

Can I sync with a second computer?

Yes. The desktop setup keeps both copies on one computer. For a two-machine setup, run the Host CLI on both systems, verify the server’s SSH host key, and connect through a tunnel. Follow the SSH walkthrough.

What happens if I edit offline?

Keep working in your usual editor. Host reconciles changes when the peer returns. If both sides edited the same file, use coven host status to find both versions, then choose the local, remote, or merged copy. Resolve a conflict.

What happens when I delete or rename a file?

When both endpoints support deletion, the next sync creates the renamed path and removes the old one. If a deletion conflicts with an edit, Host keeps a recovery copy and lets you choose the outcome. Recover a deletion or rename.

Why was my file skipped?

Save it under Castles/demo/files/ or Castles/demo/results/. Use lowercase names such as field-note.md and keep each file within 10 MiB. Host skips dotfiles, credential-like names, and other excluded paths. Check names, exclusions, and limits.

What if the installer won’t open?

The Windows v0.1.2 installer is unsigned. Use the checksum verification steps if Windows shows a publisher warning. For other startup problems, the setup guide covers platform requirements, portable Linux packages, and diagnostics.
