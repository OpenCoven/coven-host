Coven Host connects an ordinary folder to one authenticated peer. Work offline in your own editor, then reconnect to exchange files and results.

Quick start

Sync your first file.

Desktop setup guide ↗
  1. 01

    Install Coven Host

    Open the installer for macOS, Windows, or Linux. It starts a private peer on your computer and opens your Coven folder.

    Choose a download ↗
  2. 02

    Add a document

    Inside Castles/demo/, save a file such as files/note.md. The watcher sends your edits to the peer. Find results from the peer in results/.

  3. 03

    Work offline

    Keep editing if the peer disconnects. Sync resumes when it returns. If both copies changed, Host keeps both versions for you to review.

Operator guide

Working with a peer.

The desktop installer keeps both copies on your computer. To sync with another machine, start the peer on a Linux host and connect through an SSH tunnel.

Connect over SSH ↗

After connecting

coven host sync
Wait for the current sync to finish.
coven host status
Inspect pending edits, conflicts, and recovery paths, even offline.
