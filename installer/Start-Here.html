Install Coven Host

Set up an ordinary Coven folder that syncs with a private peer on this computer. Download the installer for the computer where you want to keep the folder.

Use this page on your desktop or choose a platform above.

Download installer Use the portable download

Downloads require access to the private OpenCoven repository. Once downloaded, the installers work offline.

Extract the entire offline kit to one folder. Open the installer for this computer from that folder.

Trouble downloading or opening the installer?
